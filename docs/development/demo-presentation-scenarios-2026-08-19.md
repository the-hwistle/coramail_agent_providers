# CoRA Mail Agent Demo Presentation Scenarios

작성일: 2026-08-19

목적: 2026-08-20 대표 시연용 데모 모드 동작 순서 정리

데모 URL: `http://127.0.0.1:8001`

기본 로그인: `admin` / `coramail`

## 시연 전 준비

1. 데모 서버가 실행 중인지 확인한다.
2. 브라우저에서 `http://127.0.0.1:8001/login`으로 접속한다.
3. `admin` / `coramail`로 로그인한다.
4. 화면 상단 또는 좌측 내비게이션에서 Dashboard, Inbox, Search, Settings 메뉴가 보이는지 확인한다.
5. 오늘 시연은 데모 fixture 기준으로 검증된 대표 업무 흐름을 보여주는 것이라고 먼저 설명한다.
6. 외부 계정 연결이나 임의 신규 메일 전체 품질을 보장하는 시연으로 말하지 않는다.

## 시나리오 1. Dashboard에서 전체 처리 현황 확인

사용 데이터: 데모 fixture 전체 메일 목록

1. 로그인 직후 Dashboard 화면을 연다.
2. 상단 요약 카드에서 전체 메일 수, 분류 완료, 배정 완료, 전달 상태를 순서대로 확인한다.
3. 설명한다: "메일이 들어오면 시스템이 본문과 첨부를 분석하고, 업무 유형과 처리 상태를 구조화합니다."
4. 업무 분포 영역을 가리킨다.
5. 표시된 업무 유형 중 `문의`, `발주`, `기술 문의`, `서비스 요청`, `납기 확인` 같은 일반 업무 유형을 짚는다.
6. 라우팅 또는 담당자 분포 영역을 가리킨다.
7. 설명한다: "이 제품의 핵심은 요약만 하는 것이 아니라, 근거를 바탕으로 담당 영역과 담당자를 찾는 것입니다."
8. 좌측 또는 상단 내비게이션에서 Inbox를 클릭한다.

확인할 것:

- Dashboard가 빈 화면이 아니고 요약 카드가 보이는지
- 업무 유형 분포가 보이는지
- 담당자 또는 라우팅 관련 영역이 보이는지

## 시나리오 2. Inbox에서 발주 업무 필터링과 상세 확인

사용 데이터: `PO-DEMO-2026-0812-01` 발주 메일

1. Inbox 화면을 연다.
2. 카테고리 필터 드롭다운을 클릭한다.
3. `발주`를 선택한다.
4. 목록이 발주 업무 중심으로 줄어드는지 확인한다.
5. 목록에서 `Ref PO-DEMO-2026-0812-01` badge가 붙은 행을 클릭한다.
6. 오른쪽 상세 패널에서 메일 제목 `[발주서 접수] PLC 제어반 예비품 발주 요청`을 확인한다.
7. 상세 패널에서 업무 유형이 `발주`로 표시되는지 확인한다.
8. 라우팅 또는 담당자 영역에서 담당 영역이 `영업`으로 표시되는지 확인한다.
9. 설명한다: "Inbox에서는 수신 메일을 업무 유형별로 빠르게 좁히고, 선택한 메일의 요약과 배정 상태를 한 화면에서 확인합니다."
10. 카테고리 필터를 다시 `All categories`로 돌린다.

확인할 것:

- `Ref PO-DEMO-2026-0812-01`
- 제목 `[발주서 접수] PLC 제어반 예비품 발주 요청`
- 업무 유형 `발주`
- 담당 영역 또는 라우팅 `영업`

## 시나리오 3. Inbox에서 견적 메일과 첨부 분석 Details 확인

사용 데이터: `QT-2026-0812-03` 견적 메일, 첨부 `Quotation_QT-2026-0812-03.pdf`

1. Inbox 검색 입력창에 `QT-2026-0812-03`을 입력한다.
2. 검색 결과에서 `Ref QT-2026-0812-03` badge가 붙은 행을 클릭한다.
3. 상세 패널에서 제목 `[견적서 송부] 산업용 네트워크 장비 및 전원모듈`을 확인한다.
4. 첨부 카드에서 `Quotation_QT-2026-0812-03.pdf`가 표시되는지 확인한다.
5. 첨부 카드의 `expand_more` 또는 Details 영역을 클릭해 첨부 분석 상세를 펼친다.
6. Details에서 거래처 `다원`, 거래처측 업무번호 `QT-2026-0812-03`, 총액 `5,346,000원`을 확인한다.
7. 품목 표에서 `Industrial Ethernet Switch 8 Port / DIN Rail`, `DC Power Supply Module 24V / 10A` 같은 품목이 보이는지 확인한다.
8. Mail Overview 또는 Summary 영역에서 핵심 요청과 담당자 `김민수`가 보이는지 확인한다.
9. 설명한다: "첨부에서 구조화한 필드와 품목 정보가 이후 검색 답변과 담당자 판단의 근거로 재사용됩니다."
10. Search 화면으로 이동한다.

확인할 것:

- `Ref QT-2026-0812-03`
- `Quotation_QT-2026-0812-03.pdf`
- 거래처 `다원`
- 총액 `5,346,000원`
- 담당자 `김민수`

## 시나리오 4. Search에서 견적서 납기와 총액을 근거 기반으로 답변

사용 데이터: Search 예시 `QT-2026-0812-03 견적서의 납기와 총액`

1. Search 화면을 연다.
2. 예시 버튼 `견적서 납기·총액`을 클릭한다.
3. 검색창에 `QT-2026-0812-03 견적서의 납기와 총액`이 자동 입력되는지 확인한다.
4. 답변 영역이 표시될 때까지 기다린다.
5. 답변에서 `발주 후 14일 이내`가 표시되는지 확인한다.
6. 답변에서 `5,346,000원`이 표시되는지 확인한다.
7. 근거 영역에서 `Ref QT-2026-0812-03` 또는 원본 메일 근거를 확인한다.
8. `원본 메일 보기` 버튼을 클릭한다.
9. Inbox 화면으로 이동하면서 URL에 `view=inbox`와 `email_uid`가 포함되는지 확인한다.
10. 이동한 Inbox 상세 패널에서 다시 `QT-2026-0812-03` 메일이 열리는지 확인한다.
11. 설명한다: "Search 답변은 단순 키워드 검색 결과가 아니라, 원본 메일과 첨부 분석 필드에서 확인한 값을 근거로 보여줍니다."

예상 답변:

- "QT-2026-0812-03 기준으로 납기는 발주 후 14일 이내이고, 총액은 5,346,000원입니다."

확인할 것:

- 검색창 자동 입력
- 답변의 납기 `발주 후 14일 이내`
- 답변의 총액 `5,346,000원`
- `원본 메일 보기` 클릭 후 Inbox 상세 이동

## 시나리오 5. 최신 메일 질의와 운영 설정 확인

사용 데이터: Search 예시 `가장 최신 메일이 뭐야`, Settings의 자동 배정 기준과 담당자 관리 데이터

1. Search 화면을 연다.
2. 예시 버튼 `최신 메일`을 클릭한다.
3. 검색창에 `가장 최신 메일이 뭐야`가 자동 입력되는지 확인한다.
4. 답변에서 가장 최신 메일에 대한 설명이 표시되는지 확인한다.
5. 근거 영역에서 원본 메일 근거가 표시되는지 확인한다.
6. 설명한다: "모든 질문을 같은 방식으로 처리하지 않고, 최신 메일처럼 정렬 기준이 명확한 질문은 메일함 메타데이터 기준으로 안정적으로 답합니다."
7. Settings 화면으로 이동한다.
8. `자동 배정 기준` 패널을 확인한다.
9. `담당자 우선순위 배정` 패널을 확인한다.
10. `담당자 관리` 패널에서 운영 담당자 목록이 보이는지 확인한다.
11. 설명한다: "담당자 배정은 화면에서 보이는 정책과 담당자 데이터에 기반하며, 운영 환경에서는 이 설정과 실제 수신 메일 데이터가 연결됩니다."
12. 대표가 "새 이메일이 들어오면 어떻게 보이나요?"라고 물으면 설명한다: "운영 모드에서는 새 메일을 수집한 뒤 같은 분석, 분류, 검색, 배정 흐름을 탑니다. 오늘은 외부 데이터 노출을 피하기 위해 검증된 데모 데이터로 흐름을 보여드립니다."
13. 대표가 "새 Gmail 계정을 지금 연결해보자"고 물으면 설명한다: "계정 연결은 OAuth 동의, 권한 승인, 실제 메일 노출, 수집 시간 변동이 있어 별도 내부 테스트 계정으로 검증하는 것이 안전합니다. 오늘 시연에서는 검증된 demo mode로 제품 흐름을 먼저 확인하는 것이 좋습니다."

확인할 것:

- `가장 최신 메일이 뭐야` 자동 입력
- 최신 메일 답변과 근거 표시
- Settings의 `자동 배정 기준`
- Settings의 `담당자 우선순위 배정`
- Settings의 `담당자 관리`

## 시연 마무리 순서

1. Dashboard로 돌아간다.
2. 오늘 보여준 기능을 순서대로 요약한다.
3. "Dashboard에서 전체 처리 현황을 본다."
4. "Inbox에서 업무 유형별로 좁히고 상세를 확인한다."
5. "첨부 분석 Details에서 구조화된 금액과 품목을 확인한다."
6. "Search에서 원본 근거 기반 답변을 확인하고 다시 원본 메일로 이동한다."
7. "Settings에서 자동 배정 기준과 담당자 데이터를 확인한다."
8. 남은 범위를 명확히 말한다: "임의 신규 메일 전체 품질, 신규 Gmail 계정 연결, 실제 운영 데이터 성능은 별도 검증 범위입니다."
