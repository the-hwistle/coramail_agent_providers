# Codex 개발 히스토리

이 디렉터리는 Git diff만으로 알기 어려운 장기 개발 맥락을 보존한다. 모든 Codex 상호작용을 기록하는 대화 로그가 아니다.

## 파일 구성

```text
codex-history/
├── README.md
├── entry-template.md
├── YYYY/
│   └── MM/
│       └── YYYY-MM-DD-short-topic.md
└── archive/
    └── session-log-legacy.md
```

기존 단일 누적 `session-log.md`는 과거 기록 보존을 위해 `archive/session-log-legacy.md`로 이동한다. 신규 기록은 날짜별 파일로 작성한다.

## 기록할 내용

- 반복해서 참조할 중요한 사용자 요구와 배경
- 아키텍처나 데이터 계약에 영향을 준 판단
- 어려운 오류의 근본 원인과 재발 방지 방법
- 임시 가정과 아직 검증하지 못한 위험
- 후속 작업에 필요한 정확한 재현 또는 확인 지점

## 기록하지 않을 내용

- 비밀값, 토큰, 인증 정보, 실제 고객 개인정보
- 장문의 이메일 원문이나 첨부 내용
- 전체 command output, traceback, diff
- 단순 진행 상황
- Git에서 이미 충분히 확인 가능한 파일 변경 목록

## 작성 원칙

- 한 파일은 하나의 응집된 작업 또는 결정 단위를 다룬다.
- 사실, 결정, 검증, 남은 위험을 구분한다.
- 확정된 기술 선택은 필요하면 `docs/decisions/`로 승격한다.
- 제품 범위나 사용자 시나리오 변화는 관련 제품 문서에도 반영한다.
- 과거 기록을 찾을 때는 전체 archive를 기본으로 읽지 말고 날짜·키워드로 필요한 항목만 찾는다.
