# SC-04 기술 검토 요청 분석

## 목적

도면, 사양서, 장비 사진 등 기술 자료가 포함된 메일을 식별하고, 기술 담당자가 검토해야 할 핵심 대상과 불확실성을 제시한다.

## 주요 사용자

- 업무 담당자
- 업무 관리자

## 상황

고객이 제품 호환성, 사양 검토, 고장 원인 또는 설치 가능 여부를 묻고 도면, 사진, 사양서 중 하나 이상을 첨부한다.

## 사전 조건

- 이미지와 문서 첨부파일을 분석할 수 있다.
- 기술 업무의 분류 기준이 정의되어 있다.
- 제품명, 모델명, 증상, 사양과 같은 기술 정보를 추출할 수 있다.

## 시작 조건

기술 검토 표현 또는 기술 자료 첨부가 포함된 신규 메일이 발견된다.

## 정상 흐름

1. 시스템이 메일과 첨부파일을 저장한다.
2. 첨부파일을 도면, 현장 사진, 부품 사진, 사양서 또는 매뉴얼로 구분한다.
3. 본문에서 모델명, 제품명, 고장 증상, 설치 환경, 요청사항을 추출한다.
4. 첨부파일에서 식별 가능한 기술 정보와 근거를 추출한다.
5. 메일 본문과 첨부파일 분석 결과를 결합한다.
6. AI가 기술 판단이 필요한 요청인지 판별한다.
7. 메일을 `기술`로 분류한다.
8. 관련 제품 또는 기술 분야에 맞는 담당자를 계산한다.
9. 불확실한 항목과 추가로 필요한 정보를 표시한다.
10. 사용자가 원본 자료와 분석 결과를 확인한다.

## 예외 흐름

- 이미지 해상도가 낮으면 분석 가능 범위를 제한하여 표시한다.
- 모델명 후보가 여러 개면 하나로 확정하지 않는다.
- 기술 문의와 일반 제품 문의의 점수 차이가 작으면 사람 검토 대상으로 보낸다.
- 첨부파일과 본문이 서로 다른 제품을 가리키면 충돌 상태를 표시한다.

## 기대 결과

- 업무 레이블: 기술
- 요청 행동: 호환성 검토, 사양 확인, 원인 분석 또는 설치 가능 여부 회신
- 핵심 정보: 제품명, 모델명, 증상, 사양, 설치 환경
- 담당 대상: 관련 기술 담당자
- 불확실한 정보와 추가 확인 필요 항목

## 사람 검토 조건

- 이미지 또는 도면을 충분히 해석하지 못했다.
- 모델명 또는 부품명이 여러 후보로 추출되었다.
- 첨부파일과 본문 내용이 충돌한다.
- 기술과 문의 분류 점수 차이가 작다.
- 분석 근거가 부족하다.

## 인수 기준

- 기술 메일 재현율 90% 이상
- 일반 문의를 기술 메일로 잘못 분류하는 비율 10% 이하
- 모델명·제품명 추출 정확도 90% 이상
- 멀티모달 분석 시간 P95 60초 이내
- 불확실 사례의 사람 검토 전환율 90% 이상
