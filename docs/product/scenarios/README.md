# CoRA Mail 사용자 시나리오

## 목적

이 디렉터리는 CoRA Mail이 실제 업무에서 사용되는 상황을 정의한다.

각 시나리오는 다음 작업의 기준으로 사용한다.

- 제품 기능 범위 결정
- AI 파이프라인 설계
- LLMOps 관찰 항목 정의
- 평가 데이터 구성
- 지연 시간과 품질 목표 설정
- 실패 시 사람 개입 기준 결정
- 기능별 인수 시험 작성

## 문서 목록

| ID | 시나리오 | 주요 사용자 | 주요 기능 |
|---|---|---|---|
| SC-01 | 신규 문의 메일 자동 분석 | 업무 담당자 | 메일 분류, 정보 추출 |
| SC-02 | 견적의뢰서 첨부 메일 분석 | 업무 담당자 | 첨부파일 분석, 정보 추출 |
| SC-03 | 발주 메일 식별 및 담당자 연결 | 업무 담당자 | 문맥 검색, 메일 분류, 담당자 연결 |
| SC-04 | 기술 검토 요청 분석 | 업무 담당자 | 첨부파일 분석, 기술 분류 |
| SC-05 | 클레임 및 긴급 서비스 요청 탐지 | 업무 담당자, 업무 관리자 | 긴급도 판단, 서비스 분류 |
| SC-06 | AI 오분류 수정 및 평가 데이터 축적 | 모든 사용자 | 사용자 피드백, 평가 데이터 |
| SC-07 | AI 분석 실패와 안전한 대체 흐름 | 업무 관리자, AI 운영 담당자 | 오류 격리, 재시도 |
| SC-08 | 대량 메일 유입 시 우선순위 처리 | 업무 관리자, AI 운영 담당자 | 비동기 실행, 처리량 관리 |

## 작성 규칙

각 시나리오 문서는 다음 항목을 포함한다.

1. 목적
2. 주요 사용자
3. 상황
4. 사전 조건
5. 시작 조건
6. 정상 흐름
7. 예외 흐름
8. 기대 결과
9. 사람 검토 조건
10. 인수 기준
11. LLMOps 관찰 항목
12. 평가 데이터 요구 사항
13. 관련 기능

## 우선 구현 시나리오

초기 LLMOps 개선 파이프라인에서는 다음 네 시나리오를 우선 적용한다.

1. SC-01 신규 문의 메일 자동 분석
2. SC-02 견적의뢰서 첨부 메일 분석
3. SC-03 발주 메일 식별 및 담당자 연결
4. SC-06 AI 오분류 수정 및 평가 데이터 축적

이 네 시나리오는 메일 분류, 첨부파일 분석, 문맥 검색, 담당자 연결, 사용자 피드백이라는 핵심 AI 흐름을 모두 포함한다.
